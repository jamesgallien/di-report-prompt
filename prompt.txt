For each attached drawing, extract the following fields from the title block and generate a Drawing Index report as a PDF using reportlab on 11×17 landscape paper. Do not assume, infer, or carry forward any data values — every value in the report must be explicitly extractable from the attached PDFs.
The report has a title "Drawing Index" in 14pt Helvetica Bold, centered, appearing only on the first page above the table. Each page has a centered footer in 8pt Helvetica reading "Page X of Y" where X is the current page number and Y is the total page count, determined via a two-pass build. The table occupies the remaining space on each page, with the column header row repeating on every page.
The table should have the following formatting:

Column headers: white background, black bold text, centered, smart word wrap (see rules below)
Section header rows: peach background (hex #FFDAB9), bold text, same column grid as data rows, section name in the GROUP column cell only, all other cells empty, no word wrap
Data rows: alternating white and light blue (hex #EBF0FA), centered, except the GROUP and DRAWING TITLE columns which are left-aligned
Voided drawings: included in their natural group section; drawing number displayed with -VOID appended in the PES DOC NUMBER cell; all non-blank cells in that row rendered with a thin 0.4pt strikethrough line drawn at 40% of the row height (not using ReportLab's built-in <strike> tag)
All cells: thin gray (#AAAAAA) border, 3pt padding on all sides
Font size: 5.5pt Helvetica (data) and 5.5pt Helvetica Bold (headers and section headers), consistent throughout. Row heights are single-line for all data and section header rows.
Page margins: 0.3in on all sides

The table has the following columns in this order with these widths: PACKAGE # (0.58in), GROUP (1.55in), EXPANSE DOC # (0.50in), PES DOC NUMBER (0.95in), SHT # (0.35in), INSTALL/REMOVAL/VOIDS (0.72in), REV DATE (0.55in), REV (0.35in), DRAWING TITLE (3.85in, left-aligned), SHEET SIZE (0.45in), FILE TYPE (0.42in), DATE RCV'D (0.40in), DWG REVISED THIS SUB (0.50in).
The remaining columns form a submittal tracking matrix. Each submittal consists of two columns: a submittal column (0.60in) and a REV column (0.30in), uniform for all submittals. The submittals are: 10% (09/19/25), 30% DETAIL DESIGN (11/17/25), 60% DETAIL DESIGN (02/13/26), 90% IFR (03/31/26), 90% IFC (XX/XX/XX), 100% FINAL RECORD (XX/XX/XX).
Column header word wrap rules: All column headers use smart word wrap except PACKAGE # (col 0) and SHT # (col 4) which must never wrap. Smart word wrap obeys these rules:

Wrap only at space characters or at forward slash characters, never mid-word
A forward slash that falls between two digit characters (i.e. part of a date) is not a wrap point
When wrapping at a slash, the slash attaches to the end of the preceding token
Parenthesised groups (including their parentheses) are treated as atomic tokens and never broken across lines

Column extraction rules:

PACKAGE #: leave blank
GROUP: determined by drawing number abbreviation per group assignment rules below
EXPANSE DOC #: leave blank if not present in extracted text
PES DOC NUMBER: the value of the DRAWING NUMBER field; if the drawing is voided, append -VOID
SHT #: the sheet number only, no "OF X" notation
INSTALL/REMOVAL/VOIDS: the word or phrase appearing immediately before the string "ISSUED FOR REVIEW" at the end of the extracted text
REV DATE: the date associated with the highest revision letter in the drawing history
REV: the highest revision letter in the drawing history
DRAWING TITLE: the value of the DRAWING TITLE field
SHEET SIZE: the value of the DWG SIZE field
FILE TYPE: "PDF" if GROUP is "05 - BOM", "14 - STUDIES AND REPORTS", or "16 - SPEC"; otherwise "CAD"
DATE RCV'D: leave blank
DWG REVISED THIS SUB: leave blank

Submittal matrix rules: Place an X in a submittal column if the drawing history contains a revision whose description matches that submittal's percentage. For columns labeled IFR, the description must also contain "ISSUED FOR REVIEW". For columns labeled IFC, the description must also contain "ISSUED FOR CONSTRUCTION". A plain percentage match without IFR/IFC wording satisfies non-IFR/IFC submittal columns only. The REV column for each submittal contains the revision letter of the matching history entry. If no match exists, both the X and REV cells are blank. For the 10% column specifically, also match a history entry containing "PRELIMINARY DESIGN" with no percentage if it is the first revision.
